# 風格速查表（57 種）

> AI 協作時用此表快速挑風格。確定要哪一種後，**只讀對應的 `references/guides/NN-name.md`** 取得完整規格，需要更細節再開 `examples/NN-name.html` 原始檔。

## 怎麼挑

- 使用者只給情境（例如「做個 SaaS 著陸頁」「儀表板」「很潮的活動頁」）→ 先看下方分類，挑 1-3 個候選，必要時詢問使用者。
- 使用者直接點名（例如「用 Glassmorphism」「賽博龐克風」）→ 直接對應編號。
